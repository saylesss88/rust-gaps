# Introduction

The Rust Programming Language book teaches you the language. It does not teach
you how to use it.

You'll finish it knowing what an iterator is, but not how to read a file line by
line. You'll understand ownership, but not why your CLI tool needs `BufReader`.
You'll know traits exist, but not which ones actually show up in real code and
what they're for.

This book fills those gaps. Each chapter takes something the standard resources
gloss over: a crate with poor documentation, a CS concept that Rust exposes
directly, a type whose behavior only makes sense once you've seen it break, and
works through it from the ground up with practical examples.

Topics include argument parsing with `clap`, I/O and the filesystem, and deep
dives into the types and crates you'll actually reach for once the tutorial
projects are behind you.
